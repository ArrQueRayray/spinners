# Spinners
_A JavaScript game about dodging obstacles, particularly spinning ones._

## History

<img width="360" alt="Original project of Spinners" align="right" src="https://github.com/user-attachments/assets/5e06cad1-188c-421c-8ea2-89c175dd697c" />

This project has deeper roots than you may expect—in fact, I had the idea to make a game like this back in mid-2017, which I somewhat did in a Scratch project.

You might think there's more, but in reality, there were only ever three levels in total, all in different projects.

I then proceeded to largely forget about this for the next several years or so as I pursued other things, at least until I began taking a web development class because college. With the assignment of a JavaScript game on an HTML canvas, I decided it was the perfect opportunity to act on that ol' idea.

As with my previous games, I worked incrementally to build this project, slowly familiarizing myself with things and adding more with time. And the result of it all? This.

## Description

Here's a lil' action game, the likes of The World's Hardest Game. Because what's life without a bit of nostalgia pandering?

Control the player with WASD or arrow keys, don't touch the red stuff, a bit of other stuff, and that's that.
